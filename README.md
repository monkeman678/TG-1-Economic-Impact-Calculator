# TG-1 Economic Impact Calculator

A soybean field planning calculator comparing manual spraying, conventional UAS spraying, and the TG-1 concept. Includes automatic scanning, three sampling strategies, an animated field visualization, editable operating costs, five comparison charts, and a scenario evaluation.

## Run locally

Install Node.js 18 or later, then run:

```sh
npm start
```

Open http://127.0.0.1:4173/. No package installation is required. The server binds to the local computer only. Keep it running while using the calculator.

```sh
npm test
```

The `dist/` directory is also a standalone static site that can be served by any static web host. This repository does not configure a public deployment.

## Model and sources

- Scanning and sampling assumptions originate in **Time Calculations.xlsx**. The field is square, with approximately 0.1-mile grid cells; the default 160-acre field has a 5 × 5 grid. All three sampling strategies use the same detected coordinates. Sample collection takes 40 seconds per location, with 15 minutes of logistics for nonempty missions.
- Cost defaults and formulas come from the big bordered table **A1:D21** of **NASA Project Management.xlsx**, sheet **Business-Case Spray Cost and Be**. Extracted values are retained in `dist/cost-source.json`. Original workbooks are not required at runtime.
- Actual calculated scanning and sampling time replaces the spreadsheet’s 0.75-hour placeholder. Labor is billed in whole hours rounded up for all methods. TG-1 has a fixed crew of 3 and a combined team rate of $120/hour.
- State expected loss rates come from the [Crop Protection Network soybean invertebrate pest-loss calculator](https://cropprotectionnetwork.org/yield-loss-calculator/soybean-invertebrate-pests), retrieved October 6, 2026. `dist/loss-data.json` retains the source and latest available estimate for each of 24 states: 20 use 2025 data, Kentucky 2024, Wisconsin 2023, Minnesota 2021, and Indiana 2017. Other states require a manual rate. These are nominal historical estimated losses per planted acre for all soybean invertebrate pests, not separate disease losses, untreated-loss forecasts, or proven recoverable revenue.
- The drone top-view asset comes from the supplied TG-1 project presentation. Field grids and routes are generated by the site.

The modeled margin subtracts included labor and pesticide costs from the selected loss benchmark. It is conditional, not confirmed profit. The model does not establish treatment efficacy, spraying-flight time, equipment acquisition, depreciation, maintenance, insurance, or all deployment costs. TG-1 is a concept, not an available service.

## Interface behavior

Inputs precede route choices. Selecting a route immediately reveals calculations, charts, evaluation, and feedback; flight animation does not delay results. The yield-loss reference line appears on Total Cost only. Supporting details and individual formulas are available through ⓘ buttons.

Comments and thumbs-up/down feedback are stored only in the current browser’s local storage. No feedback is sent to a server or project team.
